## 原因の切り分け

1. **必要な領域へ注視が移らない**：判断 1 から 2 では注視移動を確認した。一方、通知設定画面で別領域へ探索を続ける経路は v2 の 3 要求以内に観測していない。選択方策または現在の候補集合が探索を妨げたという仮説は残るが、不具合とは確定しない。
2. **注視しても文字や対象を認識できない**：入力画像と候補は確認できるが、内部認識は直接測定していない。e5 のクリックは利用と整合する後続行動であり、認識精度の測定ではない。設定画面で認識に失敗したとは断定できない。
3. **認識できる情報が状態へ渡らない**：combined の状態には判断 1、2、3 に対応する画像記憶が順に存在し、revision は 1、2、3。制約条件の visibleText が空なのは既存契約である。文字抽出がないこと自体を実装不具合とは扱わない。
4. **過去情報の不適切な消失や漏洩**：combined の記憶数は 1、2、3 と増え、観測済み画像を参照している。今回の保存経路に消失の証拠はない。これは他の経路の漏洩がないことの実証ではなく、ローカルの allowlist、画像参照、容量回帰で別に確認する。
5. **候補生成や分布処理が不適切**：設定画面でクリック候補が 0 件であることは観測事実。鮮明領域に対象と badge 全体が入る場合だけ候補にする現行契約で説明でき、正解を候補へ追加する修正は行わない。combined のモデル提案と sample 実選択の違いも保存したまま比較する。
6. **実行器が選択操作を実行しない**：判断 2 の click e5 後に raw screen が通知設定へ変わり、vision の back 後は UI 操作数が増える。注視では UI 操作数を増やしていない。今回の経路で実行器の誤動作を確認していない。
7. **完了判断と客観結果の接続が不適切**：current と state は done と記録上の objectiveSuccess が一致する。ただし古いログは最終 oracle/capture の独立ステータスを持たず、監査有効性は unknown。最終監査契約の現行ローカル回帰と、新規通常実行の監査で確認する。
8. **確率的選択や自主的離脱**：combined 判断 3 は sample の選択事例。ABANDONED と STUCK の終了は v2 にはない。同地点の再訪だけを異常と認定せず、予算終了を自主的離脱へ変換しない。
9. **予算や時間や操作上限**：v2 の vision と combined は API_LIMIT で終了した。API の応答時間と runner の経過時間を人間の迷いや思考時間として集計しない。

この保存経路から根拠付きで修正できる共通製品コードの不具合は確定しなかった。
今回は分析コードと回帰を追加し、候補、視覚制約、sampling、終了条件は変更しない。

## 分析コードの契約

analyzeRun(result) はファイル読取りや API を行わず、入力を変更せずに分析値を返す。
artifact-valid は記録された最終監査契約を満たす分類であり、画像ファイルの存在や hash を再検証したという意味ではない。
API、分布、操作、観測、安全停止のエラー、最終 oracle/capture エラー、監査と視覚の source hash 不一致は infra-invalid とする。
監査メタデータがない古い結果は unknown とし、比較可能へ自動昇格させない。
予算打ち切りは監査有効性と独立に保持し、完了例の指標へ混ぜない。

timeline は判断ごとの入力参照、注視、鮮明領域、記憶 revision と各 entry、候補、モデル提案、分布と抽選、実選択、実操作、結果、記録された counter を保持する。
lookEffectPairs は実行済み注視と直後の判断を対応付け、同一 raw source、異なる raw source、証拠不足を分ける。
同一画面でも、次の注視が要求位置と一致したかを別に記録する。
異なる画面の新候補を、注視だけの効果と解釈しない。

ROI は監査だけの notification-entry と notification-stop を扱い、viewport の矩形に対する注視点の包含と、鮮明領域による対象矩形全体の包含を別々に記録する。
初回の判断番号は記録済み幾何情報に基づき、読み取りや理解を表さない。
対象の右辺と下辺に等しい点は矩形の外、鮮明領域と対象の辺が一致する全体包含は true とする。
保存済み実ログには事前定義 ROI がないため、初回注視は not-recorded とし、後から正解位置を推定して補わない。
