# 補正を外したユーザー行動モードでのPersona比較

2026-11-05。入力を接続して実Jev12枠を実行したが、探索経路の差が実行ごとのばらつきを超えるPersona効果だとは確認できなかった。
Cでは確認カテゴリの自己申告と経路が3回そろった一方、同じ経路はbaseline・A・Bでも出た。人間との一致は測定していない。

## 固定した条件

共通構造のローカル検証UIのうち講座予約・変更前の1課題を使う。baseline（Personaなし）、既存A（初心者）、B（熟練者）、C（慎重な利用者）を各3回。順序はbaseline/A/B/C、A/B/C/baseline、B/C/baseline/A。4位置すべてを均等にした計画ではない。

共通モードexperience-persona-unweightedは前の補正なし方式を継承し、全4条件でbehavior=userとする。従来のgoalモードや既定値は変更しない。このため前回のgoalモードのbaselineを今回の対照として使わない。

Persona以外は同じUI、目的、初期状態、画像処理、記憶容量、候補生成、モデル、質問、argmax選択、seed、安全除外に固定した。seedは選択器の再現用であり、外部モデルの出力を固定するものではない。Personaごとに別のクリック順序や禁止経路は登録していない。ID・名前を含むPersona全体が条件で、知識、期待、傾向など各項目の寄与を個別に分離する実験ではない。

Aの既存入力には、普段スマートフォンを使うが比較実験では他条件と同じ画面サイズで操作する旨が明記されている。全条件1280×900で、スマートフォン画面の再現を主張しない。Personaを既存parserで検証・複製し、初期期待、画像条件抽出、評価、行動判断へ渡す。

最大12枠、各12判断/15UI操作/3注視/36要求/300秒、画像抽出60秒、全体432要求/66分、直列1、再送0。孤立した抽出エラーやタイムアウトはその枠を無効として保存し、次の予定枠へ進む。連続2無効、認証・利用枠・会計・入力・リプレイ・監査・安全の不整合では停止する。失敗枠の置換は行わない。この方針は実モデル実行前に固定した。

### 同じ操作と理由の違い

確認カテゴリの自己申告は baseline 8/34判断、A 6/34、B 8/34、C 27/30。Cは3回とも最初がgoal、その後の9判断がconfirmationだった。Aのuncertaintyは19/34、Bは15/34、baselineは14/34。これらは実行した独立ユーザーの人数や心理的自信を表さない。

Cの理由カテゴリは与えた期待と対応するが、それだけで知識の理解や人間らしい判断を実証しない。Personaの名前や語句に合わせて説明カテゴリを選んだ可能性も残る。AとBの経路差も条件内の揺れを伴っており、初心者と熟練者の行動分離は確認できていない。

### 同じ画像でも同じ判断入力ではない

各試行で最初に現れた画像を79件取り出すと、試行間で同じ画像の組は381組あった。しかし全381組で候補の説明まで含むcriteriaが異なり、凍結した厳格条件を満たす分布比較は0組だった。これは分布差が0だったという意味ではない。

同じ番号のクリック対象でも、既存処理が加えるモデル生成の条件説明・根拠・予測結果などが異なる。従って、同じ画面だけを根拠に入力全体が同一だったとはいわない。マッチ条件を結果を見て緩めず、厳格比較は未測定として残す。操作列の比較と、画像を使った個別の確認は別に実施した。

## 知識と制約の評価範囲

Aの不明確さへの反応は自己申告として観測したが、未知用語を理解できないかを直接調べる課題ではない。Bの認証やWebサービスの知識も、初期状態が利用中のアカウントであり十分に使う場面がない。Cの確認傾向と、個人情報を慎重に扱う制約は別物で、今回は個人情報を入力・送信する選択場面がなく、後者は未実施とする。全属性を守れたとは認定しない。

## 比較の読み方

経路距離は、監査で特定した画面の種類と実行した操作、コントロールの表示文言の列から、既存の正規化編集距離を計算する。画像ごとのローカル候補IDだけで異なる画面の操作を同一視しない。目的未達でも、有効で監査のそろった試行は比較に含む。基盤不整合や欠測のある試行は完了経路から除外し、観測済み部分を別に残す。ここでの完了経路は監査がそろった打切り時点までの記録で、目的達成を意味しない。判断上限で終わった先の行動や離脱は推定しない。

同じPersona内の距離と、異なるPersona間の距離を件数付きで示す。比較ペアは互いに独立ではなく、少数反復と欠測の偏りがある。全4条件のそろった反復が2つ以上ある場合だけ、反復内のラベルを入れ替える完全列挙の参考値を計算する。時間・実行順序を含む交換可能性は未検証であり、校正済みの有意差や因果の確証、人間らしさの点数ではない。

同じ実入力画像でも、候補の表示内容、記憶や抽出結果まで同じとは限らない。画像と候補の対応が一致する場合のモデル分布・選択を別に示し、入力全体が同一だったとはいわない。モデルの理由カテゴリは短い自己申告であり、内部判断や人間の感情の完全な記録ではない。API応答時間やブラウザーの実操作時間はユーザーの思考・読書時間に置き換えず、モデル上の行動時間は未設定とする。

## 実装上の修正

今回の独立検証で、Persona配送不一致を検知して全体を止めても、その枠が有効経路・距離・参考計算へ入るP1を発見した。補正なし設定に反する実適用でも同じ問題があった。該当する監査エラーを試行の有効性へ先に反映し、元の観測部分を残したまま比較対象から除外するよう修正した。初期の非Persona情報の不一致も集計前に試行エラーへ反映する。

修正版は親の関連53テストとbuild、独立47テスト、実際のdriverの15異常系、改変2種類の検出、通常CLIの12モック枠のリプレイを通過した。これらには重複があり合計しない。最初のFAIL、元の135モック資料、再検証の135モック資料と両版のソースZIPを保持する。モックは実モデルの行動差の証拠ではない。

## 残る範囲

この1課題と3反復だけでは、異なる操作構造や実製品への一般化、対象ユーザー集団の行動予測能力は認定できない。傾向は仮説であり、初心者が速く動いたことや慎重な利用者が確認を省いたことだけで矛盾としない。知識・制約を使う場面がなければ未実施、判断根拠が足りなければ評価不能とする。人間との一致を測るには、対応する対象ユーザーの反復記録が必要である。
