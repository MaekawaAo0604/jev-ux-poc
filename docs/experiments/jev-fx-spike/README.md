# Jev FX spike — 検証用・実売買なし

現在価格を使った Jev と固定ルールの独立比較は [COMPARISON.md](COMPARISON.md) を参照してください。
以下は先に行った過去の FOMC 声明による検証で、リアルタイム比較とは別です。

既存UXテスト本体には接続しない使い捨ての予備検証です。別リポジトリの本番ボットではありません。
依存パッケージは親ワークスペースの `ai` を使います。証券口座・注文API・常駐処理はありません。

## 実行

ワークスペースのルートで実行します。

```powershell
node --test docs/experiments/jev-fx-spike/core.test.mjs
node docs/experiments/jev-fx-spike/run.mjs
```

実行時のみ既存 `.env` のGatewayキーを読みます。キーを出力・複製しません。
初回はFRB公式資料・FREDの参考為替レートを取得し、40声明を実Jevで分類します。
入力と結果を `.cache/jev-fx-spike/` に保存し、同一入力は再利用します。
レポートは `reports/jev-fx-probe-<時刻>/` に保存します。モデルの別名はバージョン固定ではありません。

`protocol.json` は結果を見る前に固定した検証条件です。取引条件・確率閾値の後付け調整は行っていません。
確率0.70は分類の採用条件であり、利益が出る確率ではありません。

## 初回実行の結果

2026-09-24に40声明を分類。ダウンロードを含む実行は41.5秒、Jevの待ち時間合計は19.9秒でした。
40論理呼出し・41試行、成功応答に記録された入力トークンは49,752。失敗試行の課金は不明です。

2024〜2025年の評価期間では、毎回1,000 USDの固定数量で以下の結果でした。

- 単純ルール：6取引、仮定コスト控除後 −2,065円。
- 単純ルール＋Jev：6取引、−2,081円。
- Jev単独（副次的な比較）：10取引、−471円。

主比較では売買の採否がすべて一致し、Jevによる選別効果はありませんでした。16円の差は1声明1円と仮置きしたAPI費用です。
全5年間ではプラスでも、後半2年はマイナスでした。この結果は「Jevでは一切稼げない」ことも、「手離れできる」ことも証明しません。

## 制約

- 過去の参考レートによる模擬計算で、リアルタイムのデモ口座運用ではありません。
- FREDは遅れて公表され、改訂の可能性もあります。値段はbid/askでも約定値でもありません。
- モデルの学習済み知識による混入は排除できません。時系列を分けても真の未知データとは限りません。
- 発表翌観測日から1観測日だけ保有します。発表直後の値動き、市場予想との差、記者会見は対象外です。
- スプレッド・保有費用・API代は仮定です。実請求・スワップを計測した値ではありません。
- 最大DDは決済時点のみ。保有中の含み損、異常時の停止、通信障害への耐性は未検証です。
- 単純ルール自体が弱く、取引回数も少ないため、戦略全般には一般化できません。
- 本番移行は不可。次に進むなら、実時間のデモ価格と事前記録した判断を使う検証が別途必要です。
