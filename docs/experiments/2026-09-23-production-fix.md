# 本番修正の検証記録

## 採用した修正

ヘッダーの画像・図形による開閉操作を、限定した構造条件で自動 POM に追加した。
候補には位置と「文字は未取得」を記し、画像の代替テキストや隠れたパネル本文を渡さない。
図形候補は一つの小さな操作と一つの別パネルを特定できる場合に限る。
未認定のヘッダー要素は通常の自動 POM にも追加しない。

開閉時にはクリック前に特定したパネルの要素を保持し、同じ要素の実際の表示変化を確認する。
クリック後にボタンの形が変わっても、別のパネルを推測し直さない。
通信遮断、同一オリジン制限、フォーム送信禁止は維持した。

装飾の単一生成文字が本文に重ならないと確認できる場合、リンク名を取得する。
縁取り画像、影、反射、移動経路、文字の置換、複雑な変形など、描画範囲を確認できない場合は除外する。
画面外・完全透明・クリップされた CSS アイコンも操作候補にしない。

根拠判定の採用版は `partial-fact-scope-v10` とした。
ユーザーが求めた項目を、内部で推定した情報分類に置き換えない。
可否を尋ねた場合は否定回答も回答とし、方法だけを尋ねた場合に未指定の連絡先や時刻を必須条件として追加しない。
引用を選ぶ段階では部分的な事実を保持し、対象の一致、十分性、矛盾は別に確認する。
未取得の項目が残っていても、取得済みの項目の根拠を元の番号と出典で保持する。
