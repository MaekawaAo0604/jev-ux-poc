# 測定方法の検証

対象は 2026-09-22 の最終 3 試行と保存ログ判定 16 ケース。
本番コードは変更しない。
旧レポートは保存し、測定結果は `reports/measurement-2026-09-22/` に分ける。
本検証は測定器の診断であり、サイトの UX 評価や新しい自律探索の成功率ではない。

## 実施項目

- [x] 観察：実サイトのデスクトップとモバイルで表示、抽出ラベル、安全な操作候補の三段階を照合する。CSS 生成文字、通常の文字、操作要素外の文字を制御例で比較する。
- [x] 情報取得：保存済みの見学本文を、見学可否、来店方法、予約の具体的方法に分けて注釈する。最後の項目をユーザーが必須としたとは仮定しない。
- [x] 採点：従来のキーワード集計と注釈を比較する。反例を含む固定ケースで Jev の項目別回答可能性を測定する。曖昧なケースは正解率の分母から分離する。
- [x] 進捗判定：同じ保存状態で複合項目と分割項目を実 Jev に渡す。チェックリストの網羅、一次判定、根拠の採否を個別に保存する。期待結果や正解経路はモデル入力に含めない。
- [x] 探索：実行済み操作だけからページ遷移、再訪、同一辺反復、新しい画面内テキストの増分を算出する。スクロールを再訪と数えず、新規テキストを有用な情報と同一視しない。
- [x] 評価範囲：保存ログの陽性・陰性別判定と新規探索を分離し、通信失敗と目的未達も分ける。
- [x] 集計のテスト、再実行、レポートの表示を検証する。

## 実行条件

公開ページの取得とローカルのメニュー開閉だけを許可する。
フォーム送信と状態変更リクエストは禁止する。
実サイトの手動経路確認は診断と明示し、自律探索の結果に加えない。
モデル試験は事前に定めたケースを各 2 回までとし、失敗試行を除去しない。
判定テストの期待値は担当エージェントの注釈であり、人間の独立評価ではない。
少数かつ同一サイト中心の標本から、他サイトや人間一般への精度を推定しない。

## 作業分担

観察と採点の試験、探索ログの再集計は独立して実行できる。
最終評価は全結果を確認してから行う。
他の作業者による既存コード・ログは変更しない。
