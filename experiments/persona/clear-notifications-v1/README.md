# Full personas for clear notification UI

初心者A、熟練者B、慎重な利用者C。既存Personaの意味を維持し、今回は端末条件を全員同じpersonalPCへ固定した。このサービスの利用は全員初回だが、同種設定の経験は異なる。baselineはdriverがPersonaなしとして入力し、架空の第四Personaprofileは作らない。

傾向は操作指定ではない。Aに必須help、Bに必須shortcut、Cに必須basicを登録しない。詳細画面のbasic既定値と明示選択を分ける。これだけで人間の再現や単一知識属性の因果効果を認定しない。
