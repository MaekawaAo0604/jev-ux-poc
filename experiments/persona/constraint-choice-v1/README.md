# 端末制約の対照セット

同じ知識・経験・期待・傾向で、OS認証情報保存の可否×本人スマホ有無だけを変える4条件。全員がPCのブラウザーから自分のメールを確認できる。ID/表示名も入力であり、純粋な因果効果や人間の再現を証明する定義ではない。

set.json内のcanStoreCredentials/hasPhoneはharnessの実行後監査用。通常runnerへ渡すのは既存形式のPersonaだけで、正解方式・候補ID・クリック順・補正重みを渡さない。画面は全条件で同じで、初期選択はない。最初の閲覧と保存を分ける。
